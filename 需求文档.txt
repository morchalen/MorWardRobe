# SmartWardrobe（智能衣橱）整合设计方案

## 一、产品定位与设计哲学
- **定位**：AI驱动的一站式个人衣橱数字化与虚拟试衣平台。
- **核心目标**：用极简的交互、极高的AI自动化，帮助用户实现“告别混乱、减少决策、控制增量、优化存量”。
- **设计理念**：
  - **无边界极简UI**：遵循Apple HIG，纯白/深色模式，去除一切视觉干扰。
  - **逻辑闭环**：从录入 → 自动处理 → 虚拟验证 → 穿戴追踪 → 汰换提醒，完整覆盖衣物生命周期。
  - **隐私优先**：敏感图像与体型数据本地优先处理，云端传输全程加密。

## 二、技术架构全景
采用**容器化分层架构**，支持在轻量级服务器或ARM设备（如Orange Pi、NAS）上私有部署。

```
┌──────────────────────────────────────────────────┐
│                    前端 (Client)                   │
│  iOS/Android (SwiftUI/Flutter) + Web (React)       │
│  极简无边界设计，支持深色/浅色模式                  │
└──────────────────┬───────────────────────────────┘
                    │ HTTPS/WebSocket
┌──────────────────▼───────────────────────────────┐
│         网关与业务后端 (Go Fiber/Gin)               │
│  用户系统、衣物生命周期管理、穿搭推荐引擎             │
│  挂载本地存储卷，实现图片与元数据私密化管理            │
└──────────────────┬───────────────────────────────┘
                    │ gRPC / Redis / HTTP
┌──────────────────▼───────────────────────────────┐
│         AI推理服务 (Python FastAPI + GPU)          │
│  - SAM / U^2-Net: 衣物精确抠图                     │
│  - ViT 分类器: 属性分解，自动打标                    │
│  - IDM-VTON / OOTDiffusion: 虚拟试衣生成           │
│  - 人体关键点检测: 3D建模与身材测量                │
└──────────────────┬───────────────────────────────┘
                    │ 读写
┌──────────────────▼───────────────────────────────┐
│ 数据层: PostgreSQL (衣物元数据) + MinIO (图像/模型) │
│ 支持SQLite单机模式，实现完全离线可用               │
└──────────────────────────────────────────────────┘
```
- **基础设施**：全量Docker化，`docker-compose`一键启动，支持NAS、Linux服务器。
- **模型优化**：AI模型可量化至ONNX格式，降低推理门槛。

## 三、核心功能模块（严格覆盖你的要求）

### 1. 个人信息录入与数字分身
**必做功能**，构建后续所有AI应用的基准。
- **基础数据**：性别、年龄、身高、体重、常住城市。
- **精准身材测量**：
  - 手动录入三围、肩宽、腿长等。
  - **AI拍照测量**：上传正面/侧面全身照，关键点检测自动估算尺寸，生成专属3D Avatar（基于SMPL参数模型）。
- **偏好与风格录入**：风格偏好、场合标签、避讳颜色等，用于智能推荐约束。
- **数据隐私**：体态照片可仅在本地处理，不上传原始文件；云端只存储脱敏参数。

### 2. AI一键抠图（智能提取衣物）
**衣物数字化的第一步**。
- **上传场景零限制**：支持挂拍、折叠、上身实拍、背景杂乱均可。
- **全自动抠图**：基于轻量SAM或U^2-Net模型，去除背景、衣架、多余人体，输出高清透明底PNG。
- **细节优化**：自动去阴影、补光、边缘羽化，保留蕾丝、印花等复杂纹理。
- **批量与微调**：一次上传多张，批量处理；提供手动涂抹工具微调抠图边缘。

### 3. AI衣物分解 + 自动智能归类
**将无结构图片变为结构化数据**。
- **6维属性分解**：
  - 品类：上衣(T恤/衬衫/卫衣…) → 下装 → 外套 → 连衣裙 → 配饰。
  - 颜色：主色提取HEX，识别纯色/拼色/格纹/碎花。
  - 材质：棉、麻、牛仔、羊毛、丝绸、化纤等。
  - 季节：春/夏/秋/冬/四季。
  - 风格：通勤、休闲、复古、运动、极简等。
  - 版型细节：修身/宽松/高腰/长袖/翻领等。
- **自动分类入库**：系统自动创建虚拟分区（单品库、当季可穿、换季收纳），无需用户手动整理。支持自定义文件夹。
- **持续学习纠错**：用户可修正标签，模型逐步适应用户个人分类习惯。

### 4. AI虚拟试衣（换衣服）
**所见即所得的核心体验**。
- **模式一：真人照片一键换装**
  - 上传自己的全身照，选中衣橱单品，AI自动贴合身形成褶皱、并处理遮挡关系。
  - 支持上下装+外套+鞋包自由组合，实时看整套搭配效果。
- **模式二：3D数字人换装**
  - 使用个人Avatar，360°旋转查看正面、侧面、背面试穿效果。
  - 可切换站姿/坐姿，模拟真实穿着状态。
- **物理真实感**：基于扩散模型（如IDM-VTON）生成布料垂坠、光影和形体适配。
- **穿搭对比与避坑**：不同颜色/版型同框对比；系统根据身形提示“梨形身材更适合A字裙”等建议。

### 5. 全维度衣物管理系统
**衣物的动态账簿**。
- **电子档案**：购买时间、价格、品牌、穿着次数、清洗次数、维修记录等。
- **生命周期状态**：活跃 → 待洗 → 待晾晒 → 换季收纳 → 闲置待处理。
- **洗护智能提醒**：
  - 按穿着次数或时间触发水洗/干洗建议。
  - 特殊材质禁忌警告（羊毛禁机洗）。
  - 梅雨季防潮提醒。
- **换季管理**：根据实时天气自动标记当季/反季衣物，生成收纳清单。
- **闲置与汰换**：
  - 一键标记“闲置/捐赠/二手转让”。
  - AI自动生成精美商品图（抠图+白底）方便上传跳蚤市场。
  - **断舍离指数**：超过6个月/跨季未穿衣物，系统强制提示，促成“一进一出”控制总量。

### 6. 智能检索与统计
- **文字搜衣**：“黑色牛仔外套”直达目标。
- **图片搜衣**：拍照一件衣服，在衣橱里找同款或相似款。
- **衣橱报告**：品类占比、色系分布、本月购买与穿着数据、碳足迹估算。

## 四、扩展增值功能（完善闭环）
- **今日穿搭推荐**：关联实时天气、日程，自动推荐2-3套穿搭，支持虚拟试穿确认。
- **购物助手**：实体店或网上看中的款，拍照比对衣橱，智能判重并分析可搭配现有单品。
- **穿搭社区**：分享数字人试穿效果，获取搭配灵感。
- **硬件联动（可选）**：对接智能衣柜硬件，通过RFID识别衣物位置，灯光指引，一键定位取出实体衣物。
- **AR实景试衣**：调用手机摄像头，实现站立即可看新衣上身的AR体验。

## 五、极简生命周期管理法则（软件固化理念）
- **胶囊衣橱自动生成**：系统根据高频穿着和百搭单品，生成30件以内的季度核心衣橱，辅助精简。
- **一进一出原则**：录入新衣时，强提示选择一件旧衣移出活跃库，否则无法录入。
- **冗余提醒**：连续数月零穿着的衣物自动沉底并标记“待处理”，推动定期断舍离。

## 六、用户典型链路
1. **初始化**：注册 → 拍摄/录入身体数据 → 生成3D Avatar，设置偏好。
2. **批量入库**：拍摄现有衣物（可连拍） → AI自动抠图、分解属性、分类归档。
3. **日常使用**：打开App → “今天穿什么”推荐生成 → 虚拟试穿看效果 → 满意后取出实体衣物。
4. **新衣入库**：拍购衣 → 系统审查是否重复 → 强制一进一出 → 入库并推荐配套搭配。
5. **换季与清理**：系统推送换季通知 → 自动锁定过季衣物 → 分析闲置列表 → 引导转卖/捐赠。

## 七、商业化模式
- **免费版**：基础衣橱管理（上限200件）、每日3次AI试穿。
- **Pro订阅**：无限AI试穿、4K数字人、私有部署支持、高级统计与一进一出强制策略、硬件联动API。
- **差异化优势**：不只是“试衣”，而是全自动的**衣物数据库构建+智能汰换**，真正实现物理空间与数字空间的双重整理。
