# SmartWardrobe v1.0 - 基础框架版本

## 版本概述

**发布日期**: 2026-Q1
**开发周期**: 8周
**目标**: 搭建系统基础架构，实现用户管理与衣物数字化录入的核心能力

## 一、版本定位与目标

### 核心价值

- 建立稳定的技术架构底座
- 实现衣橱数字化的最小可行产品（MVP）
- 验证用户基本使用流程

### 用户价值

✅ **告别混乱**: 衣物从物理状态转为数字化管理
✅ **快速入库**: AI辅助的衣物信息录入流程
✅ **基础检索**: 支持按品类、颜色、季节等维度查找

## 二、技术栈选型

### 前端层

- **Web端**: React 18 + TypeScript + Vite
- **移动端**: Flutter 3.x（跨平台支持iOS/Android）
- **UI框架**: Tailwind CSS + Headless UI（极简无边界设计）
- **状态管理**: Zustand + React Query

### 后端层

- **主服务**: Go 1.21+ / Gin Framework
- **API风格**: RESTful + GraphQL（复杂查询）
- **实时通信**: WebSocket（后续版本预留）

### 数据层

- **关系型数据库**: PostgreSQL 15+
- **对象存储**: MinIO（私有部署）/ AWS S3（云端）
- **缓存层**: Redis 7（会话与热点数据）
- **搜索引擎**: Meilisearch v1.x（全文检索）

### 基础设施

- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx / Traefik
- **监控**: Prometheus + Grafana（基础指标）
- **日志**: ELK Stack（简化版：Loki + Promtail）

## 四、数据库设计（v1.0简化版）

### 核心表结构

```sql
-- 用户表
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    phone VARCHAR(20) UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    nickname VARCHAR(100) NOT NULL,
    avatar_url TEXT,
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 用户档案表
CREATE TABLE user_profiles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    gender VARCHAR(20) CHECK (gender IN ('male', 'female', 'other')),
    age INTEGER,
    height_cm DECIMAL(5,2),
    weight_kg DECIMAL(5,2),
    bust DECIMAL(5,2),
    waist DECIMAL(5,2),
    hip DECIMAL(5,2),
    shoulder_width DECIMAL(5,2),
    leg_length DECIMAL(5,2),
    city VARCHAR(100),
    style_preferences JSONB DEFAULT '[]', -- ["casual","minimalist"]
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 衣物表
CREATE TABLE clothes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(255), -- 可为空，AI识别后填充
    category VARCHAR(50) NOT NULL, -- tops/bottoms/outerwear/dress/accessories/shoes
    primary_color VARCHAR(7), -- HEX color
    secondary_color VARCHAR(7), -- 拼色时的第二主色
    brand VARCHAR(100),
    price DECIMAL(10,2),
    purchase_date DATE,
    seasons JSONB DEFAULT '[]', -- ["spring","autumn"]
    material VARCHAR(100), -- 手动填写或AI识别
    style_tags JSONB DEFAULT '[]',
    custom_tags JSONB DEFAULT '[]',
    image_url TEXT NOT NULL, -- 主图URL（MinIO路径）
    thumbnail_url TEXT, -- 缩略图URL
    is_favorite BOOLEAN DEFAULT false,
    folder_id UUID REFERENCES folders(id) ON DELETE SET NULL,
    wear_count INTEGER DEFAULT 0,
    status VARCHAR(20) DEFAULT 'active', -- active/archived/donated/discarded
    metadata JSONB DEFAULT '{}', -- 扩展字段
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 文件夹表
CREATE TABLE folders (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    parent_folder_id UUID REFERENCES folders(id) ON DELETE CASCADE,
    sort_order INTEGER DEFAULT 0,
    is_system BOOLEAN DEFAULT false, -- 系统预置文件夹不可删除
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 衣物图片表（支持多图）
CREATE TABLE clothing_images (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    clothing_id UUID REFERENCES clothes(id) ON DELETE CASCADE,
    image_url TEXT NOT NULL,
    image_type VARCHAR(20) DEFAULT 'additional', -- main/detail/try_on
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 索引优化

```sql
-- 性能关键索引
CREATE INDEX idx_clothes_user_category ON clothes(user_id, category);
CREATE INDEX idx_clothes_user_seasons ON clothes USING GIN(user_id, seasons);
CREATE INDEX idx_clothes_color ON clothes(primary_color);
CREATE INDEX idx_clothes_favorite ON clothes(user_id, is_favorite) WHERE is_favorite = true;
CREATE INDEX idx_folders_user_parent ON folders(user_id, parent_folder_id);
```

## 七、非功能性需求

### 性能指标

- **首屏加载时间**: < 2秒（3G网络）
- **API响应时间**: P95 < 300ms
- **图片加载**: 使用懒加载 + WebP格式
- **并发支持**: 单用户100 QPS，系统1000 QPS

### 安全要求

- **传输加密**: TLS 1.3强制
- **密码存储**: bcrypt (cost=12)
- **JWT安全**: RS256签名，15分钟Access Token
- **文件上传**: 类型校验 + 大小限制 + 病毒扫描（ClamAV）
- **SQL注入防护**: 参数化查询 + ORM安全实践
- **XSS防护**: CSP策略 + 输入转义

### 兼容性

- **浏览器**: Chrome 90+, Safari 14+, Firefox 88+, Edge 90+
- **移动端**: iOS 14+, Android 10+
- **响应式断点**:
  - Mobile: < 640px
  - Tablet: 640px - 1024px
  - Desktop: > 1024px

### 数据备份

- **PostgreSQL**: 每日全量备份 + WAL归档（保留30天）
- **MinIO**: 对象版本控制 + 跨区域复制（可选）
- **用户导出**: 支持一键导出个人全部数据（JSON + 图片包）

```bash

docker-compose -f docker-compose.dev.yml up -d
```

### 生产环境

```yaml
# docker-compose.prod.yml 核心服务
services:
  api-gateway:
    image: smartwardrobe-api:v1.0
    ports: ["8080:8080"]
    environment:
      - DATABASE_URL=postgres://...
      - REDIS_URL=redis://...
      - MINIO_ENDPOINT=minio:9000

  postgres:
    image: postgres:15-alpine
    volumes:
      - pgdata:/var/lib/postgresql/data
    environment:
      - POSTGRES_DB=smartwardrobe

  minio:
    image: minio/minio:latest
    volumes:
      - miniodata:/data
    command: server /data --console-address ":9001"
```

## 十一、已知限制与技术债务

1. **无AI能力**: 本版本完全依赖手动录入，效率较低
2. **搜索简单**: 仅支持文本匹配，无语义理解
3. **无智能推荐**: 需等待v3.0版本
4. **单租户架构**: 未实现多租户隔离（如需SaaS化需重构）
5. **图片处理有限**: 仅做压缩，无智能裁剪/增强
