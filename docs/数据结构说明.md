## 一、数据架构总览

### 1.1 实体关系图（ER图概念）

```
┌─────────────┐       ┌──────────────────┐
│   Users     │───1:1─│  UserProfiles    │
│ (用户账户)   │       │  (详细档案)       │
└──────┬──────┘       └──────────────────┘
       │
       │ 1:N
       ▼
┌─────────────┐       ┌──────────────────┐
│   Clothes   │───N:1─│     Folders      │
│  (衣物)      │       │   (文件夹)        │
└──────┬──────┘       └──────────────────┘
       │
       ├── 1:N ──> ClothingImages (图片)
       ├── 1:1 ──> AIClassifications (AI识别结果)
       ├── 1:N ──> CareLogs (洗护记录)
       ├── 1:N ──> OutfitWearLogs (穿着记录)
       ├── 1:N ──> ClothingStatusLogs (状态变更日志)
       └── 1:1 ──> ClothingEmbeddings (向量嵌入)

┌─────────────┐
│ CommunityPosts│ (社区帖子)
└──────┬──────┘
       ├── 1:N ──> Comments (评论)
       ├── N:M ──> SocialRelations (社交关系)
       └── N:1 ──> Users

┌─────────────┐
│ DeveloperApps│ (开发者应用)
└──────┬──────┘
       ├── 1:N ──> APICallLogs (调用日志)
       └── 1:N ──> WebhookEvents (Webhook事件)
```

### 1.2 数据分层策略

| 层级 | 存储位置 | 数据类型 | 示例 |
|------|---------|---------|------|
| **热数据** | PostgreSQL + Redis | 频繁访问的元数据 | 用户信息、衣物列表、今日推荐 |
| **温数据** | PostgreSQL | 历史查询数据 | 穿着历史、洗护记录、搜索历史 |
| **冷数据** | 对象存储(S3/MinIO) + 数据仓库(ClickHouse) | 归档数据 | 一年前的操作日志、统计快照 |
| **非结构化** | MinIO/S3 | 图片、视频、模型文件 | 衣物照片、试衣生成图、AI模型权重 |
| **向量数据** | Milvus/Qdrant/Faiss | 高维 embeddings | 视觉特征向量、用户偏好向量 |

## 二、核心实体数据模型

### 2.1 User（用户）

```typescript
interface User {
  // === 基础标识 ===
  id: string;                      // UUID v4, 主键
  email: string;                   // 邮箱，唯一索引
  phone?: string;                  // 手机号，唯一索引（可选）
  password_hash: string;           // bcrypt hash, cost=12
  nickname: string;                // 昵称，必填，长度2-50

  // === 头像与展示 ===
  avatar_url?: string;             // 头像URL（CDN地址）
  avatar_3d_url?: string;          // 3D数字人头像URL (v3.0+)

  // === 账户状态 ===
  is_email_verified: boolean;      // 邮箱是否已验证
  is_phone_verified: boolean;      // 手机是否已验证
  is_active: boolean;              // 账户是否激活（非删除）
  is_banned: boolean;              // 是否被封禁
  ban_reason?: string;             // 封禁原因
  banned_until?: Date;             // 封禁截止时间

  // === 订阅与权限 ===
  plan_type: PlanType;             // free | pro_individual | pro_family | business | enterprise
  plan_expires_at?: Date;          // 订阅到期时间
  features_enabled: string[];      // 启用的功能特性列表

  // === 多租户 (v5.0+) ===
  tenant_id?: string;              // 所属租户ID（个人版为自身ID）
  role_in_tenant?: TenantRole;     // owner | admin | member | viewer

  // === 时间戳 ===
  created_at: Date;
  updated_at: Date;
  last_login_at?: Date;            // 最后登录时间
  last_login_ip?: string;          // 最后登录IP
  login_count: number;             // 累计登录次数

  // === 审计字段 ===
  registered_via: 'email' | 'phone' | 'wechat' | 'apple' | 'google'; // 注册渠道
  referral_code_used?: string;      // 使用的邀请码
}

type PlanType = 'free' | 'pro_individual' | 'pro_family' | 'business' | 'enterprise';
type TenantRole = 'owner' | 'admin' | 'member' | 'viewer';
```

### 2.2 UserProfile（用户档案）

```typescript
interface UserProfile {
  id: string;                       // UUID
  user_id: string;                  // FK -> users.id, 级联删除

  // === 基础身体数据 ===
  gender: Gender;
  age?: number;                     // 年龄（可选）
  height_cm: number;                // 身高 cm (精确到0.1)
  weight_kg: number;                // 体重 kg (精确到0.1)
  city: string;                     // 常住城市
  country_code: string;             // 国家代码 CN/US/JP等

  // === 详细身材测量 ===
  body_measurements: BodyMeasurements;

  // === AI测量的补充数据 (v2.0+) ===
  ai_body_analysis?: AIBodyAnalysis;

  // === 风格偏好 ===
  style_preferences: StylePreferences;

  // === 避讳设置 ===
  avoid_colors: string[];           // 不喜欢的颜色HEX数组 ["#FFFF00"]
  avoid_styles: string[];           // 不喜欢的风格标签
  avoid_materials: string[];        // 不喜欢的材质

  // === 场合权重配置 ===
  occasion_weights: Record<OccasionType, number>;
  // { work: 0.4, casual: 0.35, formal: 0.15, sports: 0.1 }
  // 权重和应为1.0

  created_at: Date;
  updated_at: Date;
}

interface BodyMeasurements {
  bust_circumference?: number;      // 胸围 cm
  waist_circumference?: number;     // 腰围 cm
  hip_circumference?: number;       // 臀围 cm
  shoulder_width?: number;          // 肩宽 cm
  arm_length?: number;              // 臂长 cm
  leg_length?: number;              // 腿长 cm
  neck_circumference?: number;      // 颈围 cm
  inseam?: number;                  // 内长 cm（裤装）
}

interface AIBodyAnalysis {
  measured_at: Date;               // AI测量时间
  confidence_score: number;         // 测量置信度 0-1
  body_shape: BodyShapeType;        // hourglass/pear/rectangle/apple/inverted_triangle
  shape_characteristics: string[];   // ["肩窄腰细", "臀部丰满"]
  style_recommendations: string[];  // ["适合高腰线设计"]
  pose_keypoints_image_url?: string;// 关键点可视化图
  avatar_model_id?: string;         // 生成的3D Avatar ID
}

type Gender = 'male' | 'female' | 'other' | 'prefer_not_to_say';
type BodyShapeType = 'hourglass' | 'pear' | 'rectangle' | 'apple' | 'inverted_triangle' | 'athletic';
type OccasionType = 'work' | 'casual' | 'formal' | 'sports' | 'date' | 'travel' | 'home' | 'other';

interface StylePreferences {
  primary_style_tags: string[];     // 主要风格标签 ["minimalist","business_casual"]
  secondary_style_tags: string[];   // 次要风格标签
  preferred_brands: string[];       // 喜欢的品牌
  color_palette_preference: 'neutral' | 'colorful' | 'monochrome' | 'earth_tones';
  fit_preference: 'slim' | 'regular' | 'oversized' | 'varies_by_item';
}
```

### 2.3 Clothing（衣物）- 核心实体

```typescript
interface Clothing {
  // === 基础标识 ===
  id: string;                       // UUID, 主键
  user_id: string;                  // FK -> users.id
  name: string;                     // 衣物名称（可为空，AI识别后填充）

  // === 分类体系 ===
  category: CategoryType;           // 主品类
  subcategory?: string;             // 子品类（更细粒度）"wool_coat" / "skinny_jeans"
  primary_color: string;            // 主色 HEX "#2C3E50"
  secondary_color?: string;         // 第二主色（拼色时）
  color_name?: string;              // 中文色名 "深灰蓝"

  // === 品牌与购买信息 ===
  brand?: string;                   // 品牌
  price?: number;                   // 购买价格 CNY
  currency?: string;                // 货币单位 默认CNY
  purchase_date?: Date;             // 购买日期
  purchase_location?: string;       // 购买地点 "天猫旗舰店" / "ZARA南京西路店"
  size?: string;                    // 尺码 "M码" / "38" / "165/88A"

  // === 属性标签 (手动或AI识别) ===
  seasons: SeasonType[];            // 适用季节 ["spring","autumn"]
  material?: string;                // 材质描述 "70%羊毛 30%聚酯纤维"
  style_tags: string[];             // 风格标签 ["minimalist","formal"]
  custom_tags: string[];            // 用户自定义标签 ["年会必备","妈妈送的"]

  // === 图片资源 ===
  image_url: string;                // 主图URL（原始或抠图后）
  thumbnail_url: string;            // 缩略图URL
  images: ClothingImage[];          // 所有关联图片详情

  // === 状态与使用追踪 ===
  status: ClothingStatus;           // 当前状态（见状态机章节）
  is_favorite: boolean;             // 是否收藏
  folder_id?: string;               // 所属文件夹

  wear_count: number;               // 总穿着次数
  last_worn_date?: Date;            // 最后穿着日期
  wash_count: number;               // 总清洗次数
  last_wash_date?: Date;            // 最后清洗日期

  // === 扩展字段 (JSONB) ===
  metadata: ClothingMetadata;       // 灵活扩展字段容器

  // === AI增强数据 (v2.0+) ===
  ai_data?: AIClothingData;         // AI识别的完整结构化数据

  // === 成本分析 (v4.0+) ===
  cost_per_wear?: number;           // 每次穿着成本 = price / wear_count
  idle_days_count?: number;         // 连续未穿天数

  // === 时间戳 ===
  created_at: Date;
  updated_at: Date;
}

// === 子类型定义 ===

type CategoryType =
  | 'tops'                          // 上装
  | 'bottoms'                       // 下装
  | 'outerwear'                     // 外套
  | 'dress'                         // 连衣裙
  | 'accessories'                   // 配饰（包、帽、围巾、首饰、腰带、眼镜等）
  | 'shoes';                        // 鞋履

type SeasonType = 'spring' | 'summer' | 'autumn' | 'winter';

type ClothingStatus =
  | 'active'                        // 活跃可穿
  | 'pending_wash'                  // 待清洗
  | 'drying'                        // 待晾晒
  | 'dry_cleaning'                  // 干洗中
  | 'seasonal_storage'              // 换季收纳
  | 'idle'                          // 闲置待处理
  | 'donation_ready'                // 待捐赠
  | 'resale_ready'                  // 待转卖
  | 'discarded';                    // 已废弃

interface ClothingMetadata {
  // 自由扩展，常见用途：
  care_instructions?: string;       // 特殊护理说明
  original_barcode?: string;        // 条形码
  retailer_sku?: string;            // 商家SKU
  gift_from?: string;               // 礼物来源
  sentimental_value?: string;       // 情感价值备注 "结婚纪念日的裙子"
  repair_history?: Array<{           // 维修记录
    date: Date;
    description: string;
    cost: number;
  }>;
  sustainability_info?: {           // 可持续信息
    material_certification?: string; // GOTS/Oeko-Tex认证
    carbon_footprint_kg?: number;    // 生产碳足迹kg
    brand_ethics_rating?: number;    // 品牌伦理评分1-10
  };
}

interface AIClothingData {
  // v2.0+ AI识别的结构化数据
  classification_id?: string;       // 关联到ai_classifications表
  model_version: string;            // 使用的AI模型版本
  classified_at: Date;              // 识别时间
  is_user_confirmed: boolean;       // 用户是否确认无误

  segmentation: {
    segmented_image_url: string;    // 抠图后透明底PNG URL
    mask_url: string;               // Mask可视化URL
    confidence: number;              // 抠图质量置信度
  };

  classification: {
    category: {
      primary: string;
      secondary: string;
      confidence: number;
    };
    colors: ColorAnalysis;
    material: MaterialAnalysis;
    seasons: SeasonAnalysis;
    style: StyleAnalysis;
    fit_details: FitDetails;
  };
}

interface ColorAnalysis {
  primary: { hex: string; name: string; percentage: number };
  secondary?: { hex: string; name: string; percentage: number };
  pattern_type: PatternType;
  pattern_description?: string;
}
type PatternType = 'solid' | 'gradient' | 'plaid' | 'floral' | 'striped' | 'polka_dot' | 'custom';

interface MaterialAnalysis {
  primary: string;                 // "棉"
  secondary?: string;
  blend_ratio?: string;            // "80%棉/20%涤纶"
  texture_tags: string[];
  care_instructions?: CareRule;
}

interface StyleAnalysis {
  tags: string[];
  occasion_suitability: Record<OccasionType, number>; // 0-1分数
}

interface FitDetails {
  silhouette: 'slim_fit' | 'regular_fit' | 'oversized' | 'unknown';
  length: 'crop' | 'regular' | 'maxi' | 'unknown';
  neckline?: 'crew' | 'v_neck' | 'scoop' | 'henley' | 'button_down' | 'off_shoulder';
  sleeve_length?: 'sleeveless' | 'short' | 'three_quarter' | 'long' | 'unknown';
  special_features: string[];
}
```

## 四、复合数据结构详解

### 4.1 Outfit（穿搭组合）

```typescript
interface Outfit {
  id: string;                       // UUID
  user_id: string;

  // 组成部分
  garments: OutfitGarmentMap;       // 明确每件衣物的穿着部位

  // 元数据
  name?: string;                    // 用户命名的搭配名称 "周一会议战袍"
  description?: string;             // 备注
  tags: string[];                   // 标签 ["商务","秋冬"]
```

```yaml
business_rules:
  clothing:
    - rule: "一个用户最多拥有N件活跃衣物"
      constraint: "COUNT(status='active') <= user.plan.max_clothes"
      error_code: WARDROBE_CAPACITY_EXCEEDED
```

### 10.3 数据完整性检查（定时任务）

```sql
-- 示例：孤儿数据清理
-- 1. 清理无对应用户的衣物
DELETE FROM clothes WHERE user_id NOT IN (SELECT id FROM users WHERE is_active = true);

-- 2. 清理无对应衣物的图片
DELETE FROM clothing_images WHERE clothing_id NOT IN (SELECT id FROM clothes);

-- 3. 同步文件夹内的衣物计数
UPDATE folders f
SET clothing_count = (
    SELECT COUNT(*) FROM clothes c
    WHERE c.folder_id = f.id AND c.status = 'active'
)
WHERE f.user_id = $1;

-- 4. 校验状态机合法性（不应出现非法状态转换）
-- （通常在应用层保证，此处作为审计）
SELECT c.id, c.status, cl.to_status, cl.created_at
FROM clothes c
JOIN clothing_status_logs cl ON cl.clothing_id = c.id
WHERE NOT EXISTS (
    SELECT 1 FROM valid_transitions vt
    WHERE vt.from_status = COALESCE(
        (SELECT cl2.to_status FROM clothing_status_logs cl2
         WHERE cl2.clothing_id = c.id AND cl2.created_at < cl.created_at
         ORDER BY cl2.created_at DESC LIMIT 1),
        NULL
    )
    AND vt.to_status = cl.to_status
);
```
