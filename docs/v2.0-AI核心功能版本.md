## 三、核心功能模块详解

### 3.1 🎯 AI一键抠图模块（P0优先级）

#### 功能描述
用户上传任意场景的衣物照片（挂拍、折叠、上身实拍），系统自动：
1. **精准分割**：去除背景、衣架、人体等干扰元素
2. **边缘优化**：智能羽化边缘，保留蕾丝/印花细节
3. **阴影去除**：自动检测并消除投影阴影
4. **输出标准化**：生成高清PNG透明底图片（支持4K输出）

#### 技术实现流程

```python
# services/segmentation/pipeline.py
class ClothingSegmentationPipeline:
    def __init__(self, model_name="sam_vit_h"):
        self.model = load_sam_model(model_name)
        self.post_processor = EdgeRefinementProcessor()

    async def process_image(self, image_bytes: bytes) -> ProcessedResult:
        """
        完整的抠图流水线
        """
        # Step 1: 预处理（归一化、resize）
        preprocessed = self.preprocess(image_bytes)

        # Step 2: SAM推理（获取mask）
        masks = await self.model.inference(preprocessed)

        # Step 3: 后处理（选择最佳mask）
        best_mask = self.select_best_mask(masks)

        # Step 4: 边缘精细化（针对复杂纹理）
        refined_mask = self.post_processor.refine(best_mask, preprocessed)

        # Step 5: 阴影去除
        shadow_free = self.remove_shadow(preprocessed, refined_mask)

        # Step 6: 生成最终结果
        result = self.generate_transparent_png(shadow_free, refined_mask)

        return ProcessedResult(
            image=result,
            mask=refined_mask,
            confidence_score=self.calculate_confidence(refined_mask),
            processing_time=self.timer.elapsed()
        )
```

class ImageQualityAssessor:
    """在用户上传时自动评分，低质量图片提示重拍"""

    def assess(self, image: Image) -> QualityReport:
        scores = {
            'sharpness': self._calculate_sharpness(image),      # 清晰度
            'lighting': self._assess_lighting(image),           # 光照均匀性
            'color_accuracy': self._check_color_fidelity(image), # 色彩准确性
            'composition': self._evaluate_composition(image),    # 构图合理性
            'resolution': self._check_resolution(image),        # 分辨率是否达标
            'noise_level': self._estimate_noise(image),         # 噪声水平
        }

        overall_score = self._weighted_average(scores)

        if overall_score < 60:
            return QualityReport(
                score=overall_score,
                is_acceptable=False,
                issues=['分辨率过低', '光线不足', '主体不清晰'],
                suggestions=[
                    '请在明亮环境下拍摄',
                    '确保衣物占据画面60%以上',
                    '建议使用后置摄像头'
                ],
                auto_apply_enhancement=True  # 可选择自动增强
            )

        return QualityReport(score=overall_score, is_acceptable=True)

from celery import Celery

celery_app = Celery('smartwardrobe_ai',
                    broker='redis://localhost:6379/0',
                    backend='redis://localhost:6379/1')

@celery_app.task(bind=True, max_retries=3)
def process_segmentation_task(self, clothing_id: str, options: dict):
    try:
        pipeline = ClothingSegmentationPipeline()
        result = pipeline.process_image_from_clothing_id(clothing_id)
        # 回调通知API Gateway更新状态
        notify_completion(task_id=self.request.id, result=result)
        return result.to_dict()
    except Exception as e:
        raise self.retry(exc=e, countdown=60 * (2 ** self.request.retries))

### 5.2 缓存策略

```go
// API Gateway侧的多级缓存
type AICacheManager struct {
    redisClient      *redis.Client
    localCache       *ristretto.Cache  // LRU本地缓存（热数据）
    classificationTTL time.Duration     // 分类结果缓存7天
    segmentTTL       time.Duration     // 抠图结果永久缓存
}

func (m *AICacheManager) GetClassification(clothingID string) (*ClassificationResult, error) {
    // 1. 先查本地缓存（<1ms）
    if result, found := m.localCache.Get(clothingID); found {
        return result.(*ClassificationResult), nil
    }

    // 2. 再查Redis（<5ms）
    cached, err := m.redisClient.Get(ctx, fmt.Sprintf("ai:class:%s", clothingID)).Result()
    if err == nil {
        result := deserialize(cached)
        m.localCache.SetWithTTL(clothingID, result, 1, 10*time.Minute)
        return result, nil
    }

    // 3. 缓存未命中，触发AI处理（异步）
    return nil, ErrCacheMiss
}
```

## 九、已知限制与技术债务

1. **GPU依赖**: 无GPU时性能下降10-20倍（需明确告知用户）
2. **复杂场景局限**: 重叠衣物、极端光照条件下准确率下降
3. **材质识别盲区**: 无法通过图片确定 exact 成分比例（需吊牌OCR辅助，v3.0规划）
4. **模型更新成本**: 全量替换模型需停机维护（考虑滚动更新方案）
5. **隐私考量**: AI处理涉及外部API调用时需加密传输（本地优先策略）
